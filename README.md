# NIVORA | منصة الفخامة والأناقة

![NIVORA Logo](https://via.placeholder.com/150x50/0B0B0B/C0C0C0?text=NIVORA)

**NIVORA** هي منصة تجارة إلكترونية متكاملة تجمع بين المجوهرات الفضية (925)، العطور الفاخرة، الساعات، والنظارات الشمسية. تم تصميم الموقع ليعكس هوية بصرية فخمة (Dark Luxury) مع تجربة مستخدم سلسة، ونظام إدارة محتوى (CMS) ذكي يعتمد على استيراد المنتجات من منصات مثل AliExpress و Amazon (Dropshipping).

---

## 🎯 أهداف المشروع
1. **واجهة مستخدم فاخرة:** تصميم داكن مع لمسات فضية وذهبية، وخطوط كلاسيكية (Playfair Display) لإبراز الفخامة.
2. **نظام إدارة ذكي:** لوحة تحكم (Admin Panel) تسمح باستيراد المنتجات عبر الروابط، وحساب التكلفة النهائية (سعر المنتج + الشحن + هامش الربح) تلقائيًا.
3. **نظام متعدد الفئات:** إدارة المخزون لكل منتج (فضة، عطور، ساعات، نظارات).
4. **أمان متقدم:** تطبيق 10-15 جدار حماية (Firewall) لصد الاختراقات.
5. **بوابة دفع:** ربط متجر PayPal بالحساب `florintoursim@gmail.com`.

---

## 🛠️ التقنيات المستخدمة (المرحلة الحالية)
- **الواجهة الأمامية (Frontend):** HTML5, CSS3, JavaScript (Vanilla JS).
- **الخطوط:** Google Fonts (Playfair Display, Montserrat).
- **التصميم:** متجاوب (Responsive)، يدعم اللغة العربية (RTL).
- **التخزين المؤقت:** يتم تخزين المنتجات في مصفوفة `productsDB` داخل `script.js` (محاكاة لقاعدة البيانات).

> **ملاحظة:** هذه المرحلة هي **نموذج أولي (Prototype)** للواجهة الأمامية فقط. لم يتم ربط قاعدة بيانات حقيقية أو API بعد.
