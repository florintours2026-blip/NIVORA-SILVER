# NIVORA SILVER — Fixed Build

هذه النسخة تعالج النسخة السابقة التي كانت تحتوي على صفحات Placeholder.

## ما تم إصلاحه
- واجهة متجر كاملة RTL ومتجاوبة للهاتف.
- صور ومنتجات تجريبية جاهزة للعرض فوراً.
- صفحات المتجر والفئات وتفاصيل المنتج.
- السلة وإتمام الطلب وحفظ الطلبات في المتصفح.
- تسجيل حساب العميل وتسجيل الدخول وتسجيل الخروج.
- صفحة دخول الإدارة.
- بيانات دخول العرض: `admin` / `123456`.
- لوحة إدارة للمنتجات والطلبات والعملاء والمخزون والمحاسبة والتقارير.
- رابط موحد للهوية والشعار.
- دعم تشغيل الواجهة وحدها، أو تشغيلها مع Express API.
- `render.yaml` جاهز للنشر كخدمة Node واحدة.

## التشغيل
```bash
npm install
npm start
```

ثم افتح الصفحة الرئيسية.

> وضع العرض لا يحتاج PostgreSQL. عند ربط قاعدة البيانات والـAPI لاحقاً يمكن استبدال بيانات العرض بمصدر البيانات الحقيقي.
