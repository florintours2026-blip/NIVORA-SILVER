NIVORA DESIGN LAYER

This package contains the storefront files that control the visual shell and shared presentation of the NIVORA website.

Included:
- index.html: storefront homepage entry point
- assets/css: global, layout, header, navigation, home, components, cards, footer, responsive and RTL styles
- assets/js: shared storefront rendering/navigation/header/card/image behavior
- assets/logo: NIVORA logo assets

Important:
These are the existing project files extracted as a separate design layer. They have NOT been replaced with the new luxury design yet. The next step is to modify these files to implement the approved NIVORA luxury direction while preserving the existing functionality.
