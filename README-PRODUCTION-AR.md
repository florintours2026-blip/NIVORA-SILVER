# NIVORA SILVER — نسخة التشغيل الأولى القابلة للبيع

هذه النسخة ليست وعدًا بأن أي متجر خارجي سيقبل الاستيراد الآلي دائمًا. الاستيراد يعمل من البيانات العامة التي تسمح بها صفحة المنتج، ويستخدم Backend محميًا للتحقق من هوية مدير Firebase قبل جلب الصفحة.

## ما تم تجهيزه

- متجر عربي RTL متجاوب.
- Firebase Authentication + Firestore + Storage الموجودان في المشروع.
- كتالوج منتجات قابل للإضافة والتعديل والحذف.
- استيراد من رابط Amazon / Noon / Alibaba / AliExpress عبر Backend.
- معاينة المنتج قبل النشر.
- استخراج الاسم والوصف والصور والسعر والعملة وSKU والعلامة التجارية قدر الإمكان.
- تصنيف آلي أولي إلى الساعات والعطور والمجوهرات والنظارات الشمسية وغيرها.
- حفظ تكلفة المورد في مجموعة `productPrivate` ولا تُقرأ للزوار.
- طلب "اطلب توفير هذا المنتج" من العميل.
- صفحة إدارية لطلبات التوفير مع حالات: جديد، تم التواصل، تم طلبه من المورد، في الشحن، تم التسليم، ملغي.
- إدارة الطلبات وتغيير الحالة.
- تتبع اهتمامات العملاء بعد موافقة الخصوصية.
- GA4 اختياري؛ لا يبدأ قبل ضبط Measurement ID وقبول التتبع.
- حماية أساسية ضد SSRF في مستورد الروابط، تحديد المصادر، مهلة اتصال، منع إعادة التوجيه غير المحدود، وحد للمحاولات.
- قواعد Firestore تمنع الزوار من تعديل المنتجات أو البيانات الإدارية.

## التشغيل من الهاتف

1. فك الضغط عن مجلد المشروع في الهاتف.
2. ارفع الملفات إلى GitHub أو إلى الاستضافة التي تستخدمها.
3. شغّل Backend على Render/Railway أو أي Node.js host.
4. في `assets/js/config.js` غيّر `apiBaseUrl` إلى عنوان Backend إذا كان منفصلًا عن الاستور.
5. في بيئة Backend ضع:
   - `FIREBASE_WEB_API_KEY`
   - `IMPORT_ADMIN_EMAILS`
   - `CORS_ORIGIN`
6. في Firebase أنشئ مستخدم المدير، ثم أنشئ له مستند `admins/{UID}` بدور `admin` أو `manager`.
7. انشر `firestore.rules` و`storage.rules`.
8. لا تضع أي Service Account JSON أو Private Key داخل مجلد الموقع.
9. لا تضع كلمة مرور أو مفتاح API سري داخل `assets/js`.

## استيراد المنتجات

من لوحة الإدارة افتح **استيراد المنتجات** ثم الصق الرابط. إذا سمح الموقع بالوصول العام، سيعود النظام بمعاينة. إذا منع المصدر الروبوتات أو كانت البيانات تُنشأ بواسطة JavaScript فقط، قد تعود بيانات ناقصة؛ عندها راجع المنتج يدويًا بدل محاولة تجاوز الحماية.

## الذكاء الاصطناعي

الموجود حاليًا هو **Smart Catalog Automation**: تصنيف آلي، حساب سعر بيع مقترح، كشف حقول ناقصة، وتسجيل سلوك العملاء. لم يتم ربط نموذج ذكاء اصطناعي خارجي بمفتاح سري حتى لا تصبح تكلفة أو صلاحيات طرف ثالث شرطًا لتشغيل المتجر. يمكن إضافة نموذج AI لاحقًا في Backend دون إعادة بناء المتجر.

## قبل الإطلاق التجاري

- ربط بوابة دفع فعلية.
- اختبار الاستيراد على حسابات/صفحات حقيقية للمصادر الأربعة.
- إضافة إشعارات SMS/WhatsApp أو البريد.
- مراجعة سياسة الخصوصية والموافقة الإعلانية حسب الدولة التي سيعمل فيها المتجر.
- إضافة إنشاء طلب المورد آليًا فقط إذا كان المصدر يوفر API/affiliate/order API مصرحًا به.
- مراجعة أمنية خارجية قبل تخزين بيانات دفع أو تنفيذ شراء آلي نيابة عن المتجر.
